
# Тема контрольной работы №4
Разработка интерактивного интернет-магазина с использованием JavaScript: работа с массивами данных, DOM, событиями, фильтрацией, сортировкой, поиском, корзиной и валидацией форм.

## На основе какой КР создан проект
Проект создан на основе Контрольной работы №3 (верстка многостраничного сайта: HTML, CSS, адаптивная верстка, БЭМ).

## Структура проекта
```text
/

├── cart.html           # Страница корзины (управление товарами)

│   ├── style.css       # Основные стили проекта
│   └── responsive.css  # Адаптивность для мобильных устройств
├── js/
│   ├── data.js         # Массив товаров (база данных)
│   ├── catalog.js      # Логика каталога (поиск, фильтры, сортировка, рендер)
│   ├── cart.js         # Логика корзины (добавление, удаление, подсчет, localStorage)
│   ├── main.js         # Вспомогательные скрипты (например, скролл наверх)
│   └── order.js        # Логика формы заявки (валидация)
└── images/             # Изображения товаров и иконки
```
## Описание JS-файлов

- **`data.js`** — содержит глобальный массив `products` с объектами товаров. Экспортируется в `window.products` для доступа из других скриптов.
- **`catalog.js`** — отвечает за рендеринг сетки товаров, реализует логику поиска, фильтрации по категориям, фильтрации по цене и сортировки.
- **`cart.js`** — управляет состоянием корзины: чтение/запись в `localStorage`, добавление товаров, изменение количества (от 1 до 99), удаление, пересчет итоговой стоимости и обновление интерфейса корзины.
- **`order.js`** — обрабатывает форму оформления заказа, выполняет валидацию полей (имя, телефон, email) и блокирует отправку при наличии ошибок.
- **`main.js`** — содержит общие скрипты (например, функционал кнопки «Наверх»).

## Описание массива товаров

Массив `products` в `data.js` содержит объекты со следующими свойствами:

- `id` (*number*) — уникальный идентификатор товара;
- `title` (*string*) — название товара;
- `category` (*string*) — категория (audio, keyboards, laptops, home, tvs);
- `price` (*number*) — цена в рублях;
- `isAvailable` (*boolean*) — наличие товара на складе;
- `image` (*string*) — путь к изображению;
- `description` (*string*) — краткое описание товара.

## Описание поиска

Поиск реализован в `catalog.js` (функция `searchProducts`). При вводе текста в поле поиска (`#catalog-search`) значение приводится к нижнему регистру и обрезаются пробелы (`trim()`). Фильтрация происходит с помощью метода `includes()`. Поиск работает в режиме реального времени при каждом вводе символа.

## Описание фильтрации

- **По категориям:** реализована функцией `filterProductsByCategory`. Значение берется из `select` с id `category-filter`.
- **По цене:** реализована функцией `getProductsByPriceRange`. Берет значения из полей `#price-from` и `#price-to` и оставляет только те товары, цена которых входит в указанный диапазон.

## Описание сортировки

Сортировка реализована функцией `sortProductsByPrice`. Она принимает направление сортировки:

- `price-asc` — сначала дешевле;
- `price-desc` — сначала дороже;
- `title-asc` — по названию А-Я.

Для сортировки по названию используется метод `localeCompare` с локалью `ru` для корректного сравнения кириллицы.

## Описание валидации формы

Валидация формы (в `order.html`) происходит на стороне клиента (в `order.js`).

- Проверяются обязательные поля (имя, телефон, email) и минимальная длина ввода.
- Формат электронной почты проверяется с помощью регулярного выражения.
- Если есть ошибки, форма не отправляется, а пользователю выводятся сообщения под соответствующими полями.
- Атрибуты `aria-invalid` обновляются для доступности.

## Описание безопасного вывода данных

При динамическом создании карточек и элементов корзины (в `catalog.js` и `cart.js`) используется свойство `textContent`, а не `innerHTML`. Это предотвращает выполнение любого вредоносного скрипта (XSS-атаки), если в названии товара или описании окажется HTML-тег.

## Описание самостоятельных доработок

1. **Доработка корзины:** реализована сложная логика работы с `localStorage`, добавлена валидация данных при восстановлении корзины (защита от сбоев и дубликатов), лимит на количество товаров (от 1 до 99).
2. **Дизайн корзины:** карточка товара переработана с использованием `CSS Grid` (3 колонки), кнопка удаления заменена на `SVG`-иконку мусорки.
3. **Липкий футер:** с помощью `Flexbox` (`display: flex; flex-direction: column; min-height: 100vh` для `body` и `flex-grow: 1` для `main`) футер всегда прижат к низу экрана, даже если контента мало.
4. **Доступность (Accessibility):** добавлены атрибуты `aria-label`, `aria-live` (для уведомлений), `aria-invalid` (для полей с ошибками).
5. **Адаптивность:** сетка корзины и каталога адаптируется под мобильные устройства (медиа-запросы).

## Инструкция по запуску

1. Скачайте проект (или склонируйте репозиторий).
2. Откройте проект в любом редакторе кода (например, **VS Code**).
3. Используйте расширение **Live Server** в VS Code, либо запустите локальный сервер (например, `python -m http.server` в папке с проектом).
4. Откройте в браузере `http://127.0.0.1:5501/catalog.html` (или `http://localhost:8000`).
